# 🗺️ 臺東協會與文健站·事務設備巡訪地圖 (Taitung OA Field Map)

> **專為辦公室事務設備（OA 影印機租賃、複合機、印表機、碎紙機、弱電系統、監視門禁、電腦主機與電話總機）業務團隊打造之臺東外勤巡訪與商機管理系統。**  
> 完整收錄 **臺東縣 16 鄉鎮市 · 114 所原住民文化健康站 (文健站) · 587 家立案協會與人民團體 · 合計 701 處實體拜訪點**！

---

## 🌟 核心設計與業務特色

### 1. 專注辦公室事務設備 (OA) 拜訪，排除無效資訊
* 不顯示繁雜的社福或個人長照護理資訊，聚焦外勤業務最在意的關鍵資訊：
  * **單位名稱與機構類別**（🏡 文健站 / 🏛️ 立案協會）
  * **負責人 / 理事長 / 站長 / 總幹事**
  * **聯絡電話 / 手機**（支援手機點擊一鍵直接撥號 `tel:`）
  * **實體會址 / 據點地址**（支援一鍵呼叫 Google Maps App 規劃路線）
  * **OA 開拓評級**（`⭐ 高印量潛力戶`、`🖨️ A3/A4 複合機`、`💻 弱電/監控/視訊`、`📄 耗材與定期合約`）

### 2. 臺東 16 鄉鎮市雙層導覽（依五大地理動線劃分）
* **第一層（5 大地理動線）**：
  1. **🏙️ 市區生活圈**：臺東市 (301 家)
  2. **🌊 東部海岸線**：卑南鄉 (45 家)、東河鄉 (25 家)、成功鎮 (39 家)、長濱鄉 (27 家)
  3. **🌾 花東縱谷線**：鹿野鄉 (43 家)、延平鄉 (18 家)、關山鎮 (26 家)、海端鄉 (20 家)、池上鄉 (27 家)
  4. **⛰️ 南迴山海線**：太麻里鄉 (43 家)、金峰鄉 (18 家)、大武鄉 (26 家)、達仁鄉 (20 家)
  5. **🏝️ 離島專區**：綠島鄉 (8 家)、蘭嶼鄉 (15 家)
* **第二層（16 鄉鎮市切換列）**：即時切換，地圖平滑飛入 (`flyTo`) 該鄉鎮核心。

### 3. 動態「同路 / 同部落」巡訪快篩 (Proximity Filter)
* 臺東地形狹長，外勤奔波動線成本極高。系統自動提取同鄉鎮內的關鍵路段與主要部落（如：`都蘭村`、`更生路`、`土坂村`、`中華路`、`大武街`、`初鹿村`、`新港` 等）。
* 點擊任一路名標籤，立刻列出同一直線上的所有拜訪點，一趟出車連續拜訪！

### 4. 外勤業務 CRM 拜訪筆記系統 (Visit Log)
* 在卡片或地圖圖釘上點擊 `📋 拜訪紀錄`，30 秒快速紀錄：
  * **洽談階段**：初次拜訪/遞名片、掌握現有機型/印量、提供租賃報價單、樣機展示體驗、簽約成交、定期抄錶維護/送耗材、租約未到期(預約回訪)、暫無需求。
  * **接洽窗口與職稱**（理事長、站長、總幹事、執行長、會計/照服員）。
  * **設備現況與痛點筆記**（例：現有影印機老舊常夾紙、每月黑白2000張彩色500張、現有租約到年底、考慮升級彩色雙面掃描機型）。
  * **下次預計回訪與待辦提醒**。
* **資料保全**：紀錄儲存於瀏覽器本機 (`localStorage`)，重新整理或版本更新絕不遺失。
* **CSV 匯出繁中報表（Excel 雙擊開絕不亂碼）**：帶有 UTF-8 BOM，一鍵匯出完整中文業務報表。

### 5. 官方資料來源與定時自動更新附註 (Header & Footer)
* **標頭即時標記**：`🕒 資料更新時間：2026年10月01日 (固定每月 1 號排程校驗)`
* **資料來源附註**：`🏛️ 資料來源：臺東縣政府民政處、社會處、原民處、原住民族委員會公開清冊`

### 6. 每月 1 號定時自動更新機器人 (GitHub Actions)
* 每月 1 號上午 09:00（UTC 01:00），GitHub Actions 自動啟動爬蟲，對齊最新立案協會與文健站清冊。
* 增量比對，保護使用者在外勤建立的個人拜訪筆記與狀態，自動重新編譯並推送到 GitHub Pages。

## 🚀 快速啟動與使用指南

### 方法一：本機直接開啟（免安裝環境）
雙擊專案目錄下的 **`啟動臺東事務設備巡訪地圖.bat`**，即可在 Chrome / Edge 瀏覽器離線秒開！

### 方法二：部署至 GitHub Pages 線上免安裝版
1. 在 GitHub 上建立全新公開 Repository（例如 `taitung-field-map`）。
2. 將本專案資料夾推送到 GitHub：
   ```bash
   git init
   git add .
   git commit -m "feat: 首次發布臺東協會與文健站事務設備巡訪地圖"
   git branch -M main
   git remote add origin https://github.com/您的帳號/taitung-field-map.git
   git push -u origin main
   ```
3. 進入 GitHub Repository 的 **Settings -> Pages**，Source 選擇 `Deploy from a branch` -> `main` / `/(root)`，點擊 Save。
4. 即可在手機與電腦隨時開啟 `https://您的帳號.github.io/taitung-field-map/` 使用！

### 方法三：手動重新編譯資料庫與網頁
```bash
# 1. 重新整合資料庫
python generate_taitung_database.py

# 2. 重新編譯生成單頁 index.html
python build_taitung_html.py
```
